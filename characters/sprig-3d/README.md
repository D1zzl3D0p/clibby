# Sprig 3D

A ceramic succulent pot with rigid green leaves and two legs.

This first live base uses two continuous skinned legs, the shared contact-preserving
walk/turn/drop system and real head/lens/crown orientation. Eyes blink only where
separate eye geometry exists. Decorative arms and wings do not advertise reach or
flight. Its `calm` disposition changes bounded quiet-rest intervals and
activity weights through the existing scheduler.

Pending signature work: An independently targeted leaf presentation.

Editable source: `tools/author_catalogue_bipeds.py` with
`tools/catalogue_asset.py`. Original MIT-licensed geometry and atlas; GLB has no
animation clips. Validation and provenance accompany each export. The runtime
uses a fixed trusted identity and deployed converted assets, not downloaded QML.

Informational presentation metadata accompanies the rig; the resident's built-in
configuration currently selects the 96-pixel source, 80 logical pixels per metre,
15.4-degree camera elevation and a three-quarter heading. Native render captures
are separate from desktop interaction and energy acceptance.
