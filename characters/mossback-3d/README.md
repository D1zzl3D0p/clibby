# Mossback 3D

Low tortoise with a rigid faceted shell, broad scutes, one moss patch and short legs.

Original MIT-licensed geometry and nearest-sampled palette. Rebuild with Blender using `tools/author_catalogue_quadrupeds.py -- mossback`. The editable `.blend`, skin `.glb`, atlas, authored rest rig, per-influence measured bounds, validation and provenance accompany each package.

Four canonical feet use continuous weighted limbs, procedural quadruped walking, attention, blink and the existing pickup/drop contract. Neck retreat and shell retraction are not implemented. Native desktop motion and appearance require runtime acceptance; Blender stills establish artwork only.

The rig presentation values record the intended runtime camera; the initial resident registry supplies those values explicitly. Blender artwork previews use a separate authoring camera.
