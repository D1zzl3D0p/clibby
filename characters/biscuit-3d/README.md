# Biscuit 3D

Blunt-headed capybara with a broad barrel body, tiny round ears and short legs.

Original MIT-licensed geometry and nearest-sampled palette. Rebuild with Blender using `tools/author_catalogue_quadrupeds.py -- biscuit`. The editable `.blend`, skin `.glb`, atlas, authored rest rig, per-influence measured bounds, validation and provenance accompany each package.

Four canonical feet use continuous weighted limbs, procedural quadruped walking, attention, blink and the existing pickup/drop contract. Sitting and stretching transitions are not implemented. Native desktop motion and appearance require runtime acceptance; Blender stills establish artwork only.

The rig presentation values record the intended runtime camera; the initial resident registry supplies those values explicitly. Blender artwork previews use a separate authoring camera.
