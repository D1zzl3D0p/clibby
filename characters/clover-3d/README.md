# Clover 3D

Cream lop rabbit with dropped ears, high haunches and a short cotton tail.

Original MIT-licensed geometry and nearest-sampled palette. Rebuild with Blender using `tools/author_catalogue_quadrupeds.py -- clover`. The editable `.blend`, skin `.glb`, atlas, authored rest rig, per-influence measured bounds, validation and provenance accompany each package.

Four canonical feet use continuous weighted limbs, procedural quadruped walking, attention, blink and the existing pickup/drop contract. Uses an ordinary four-beat walk; hopping is not implemented. Native desktop motion and appearance require runtime acceptance; Blender stills establish artwork only.

The rig presentation values record the intended runtime camera; the initial resident registry supplies those values explicitly. Blender artwork previews use a separate authoring camera.
