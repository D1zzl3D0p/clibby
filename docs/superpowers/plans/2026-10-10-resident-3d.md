# Resident 3D Implementation Plan

**Goal:** Make the accepted live werewolf selectable in the desktop resident.

**Architecture:** Reuse the resident host, scheduler, sessions and controls. A timerless scene binding draws a model whose world movement is proposed by the shared motion core and realized through native window placement. Trusted converted assets deploy beside the executable.

**Spec:** `docs/3d-resident-plan.md`. The user authorized implementation of this existing design; no additional approval rounds are needed.

**Constraints:** C++17, optional Qt Quick 3D, existing 2D fallback, exact floor contacts, no per-frame GPU readback, no independent resident animation timer. Native desktop and energy acceptance require separate evidence.

## Ownership and delivery

- [x] Motion worker: `qt/characters3d/pose.{h,cpp}`, `tests.cpp`; add reset/propose/realize, quantized placement and blocked-edge tests while retaining preview step.
- [x] Render worker: `qt/preview3d/`, `qt/characters3d/CMakeLists.txt`; timerless binding, embeddable transparent stage, projected masks/anchors, trusted deployed resources; retain joint and presentation checks.
- [x] Host worker: `qt/resident/desktop_host.{h,cpp}`, `host_tests.cpp`; prepared-item installation, metadata, masks and rollback tests without a Quick3D dependency.
- [x] Root: resident adapter, package descriptor, selection/restoration, walking controls, shared scheduling and reactions; unsupported-renderer rollback and native-capable lifecycle tests.
- [x] Root: full Release build, CTest and Python regression checks, optional-modules-disabled build, scene/live-joint verification, independent review, documentation.

## Review focus

Selection must preserve the live pet and sessions on failure. Pause/hide must cancel movement and reactions without leaving timers. Centimeters and logical pixels must convert exactly once. The projected walking direction must be horizontal. Conservative masks must include gesture extremes while retaining useful click-through around the pet.
