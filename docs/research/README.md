# Research archive

These reports and source notes informed Clibby's utility features and character
expansion. They preserve the project's earlier Better Pets name and the state of
implementation when researched, in October 2026. Statements about the "current"
lineup, missing features and proposed work are historical; use the
[current handoff](../handoff.md) for today's implementation status.

Product comparisons, audience hypotheses and vendor resource claims are not
independent measurements of demand, desktop compatibility or battery impact.
Source links remain with their findings, including explicit limits where an app
or feature could not be inspected.

## Reports

- [Natural companion turning](reports/Natural%20companion%20turning.md) studies
  human and quadruped turns and audits the rejected small-step/speed constraints.
- [Pet utility and toolbox design](reports/Pet%20utility%20and%20toolbox%20design.md)
  compares work notifications, attention inboxes and summoned tools.
- [Better Pets expansion catalogue](reports/Better%20Pets%20expansion%20catalogue.md)
  proposes 18 original character directions and an initial implementation order.
